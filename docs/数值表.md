# 数值表

> 这张表只回答三个问题：**现在是多少、在哪改、改了什么会变**。它不是数据源——调数值仍然去对应的 `.tres` 或脚本里改，改完回来更新这一行。
>
> 「目标值」一列未定就写"待定"。设计讨论定了目标值再填，不要在这里发明数值。

## 怎么读

- **生效位置**：真正读取这个值的文件与行。写了"不生效"的，说明配了但没人读。
- **状态**：生效 / 不生效（配了没人读）/ 未接线（字段或数据结构有，逻辑没实现）。

## 还没有数值的地方

这些位置目前没有可调参数，属于设计未定而不是遗漏：

- 崩解度的减益曲线与"绕经已访问节点的额外上升"系数（只有比例和信号，`MapRun.get_decay_ratio()`）
- 战斗胜负的金币奖励公式
- 商店删牌 / 增强的次数与价格
- 事件池权重、事件出现概率
- 敌人行为权重（`EnemyActionState.next_state` 是线性后继，没有随机）
- 收集品的数值与出现率
- 局外养成的评价标准
