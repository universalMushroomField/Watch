# 地图系统

地图参考《杀戮尖塔》的节点推进方式，但拓扑是自由网状：节点可以任意连线，允许回头、跳层和同层捷径，不要求每层节点数一致。

## 节点类型

| 类型 | 说明 |
| --- | --- |
| 起点 | 每幕开始的位置，已自动访问 |
| 战斗 | 普通战斗，胜利后获得金币 |
| 精英战斗 | 更难的战斗，金币更多 |
| 未知事件 | 随机触发一个事件，按选项结算 |
| 宝箱 | 获得金币 |
| 商店 | 购买卡牌或治疗，库存有限 |
| 休息点 | 恢复最大生命的一定比例 |
| 关底 Boss | 本幕终点，进入后可以开启下一幕 |

## 崩解度

崩解度 = 本幕已访问节点数 / 本幕节点总数，每幕开始时重置。起点计入已访问，所以开局是 `1 / 节点总数`。回头再次进入已访问节点不会增加崩解度。

目前只提供数值与信号（`MapRun.decay_changed`、`MapRun.act_completed`），尚未绑定任何减益效果，方便后续单独设计。

## 主要脚本

| 文件 | 职责 |
| --- | --- |
| `map/map_config.gd` | 地图生成参数（层数、每层节点数、各类节点数量、连线概率） |
| `map/map_node.gd` | 单个节点：类型、层数、归一化坐标、相邻节点 |
| `map/map_graph.gd` | 节点集合与无向边，提供连通性检查 |
| `map/map_generator.gd` | 生成地图、修补连通性、按配额分配节点类型 |
| `map/map_run.gd` | 一局游戏的地图进度：当前节点、崩解度、切换幕 |
| `map/map_player_state.gd` | 生命、金币、卡组副本，供事件和商店结算 |
| `map/map_canvas.gd` | 绘制地图并把点击换算成节点 |
| `map/map_view.gd` | 调试界面：顶栏、崩解度、节点面板 |

## 内容资源

- `map/data/map_config.tres`：默认地图参数。
- `map/data/map_content_pool.tres`：事件、商店库存、各类金币与治疗比例。
- `map/data/events/*.tres`：示例事件。
- `map/data/shop_stock.tres`：示例商店库存。

## 调整生成结果

在 `map/data/map_config.tres` 中修改：

- `band_count`：层数，Boss 固定在最后一层。
- `min_nodes_per_band` / `max_nodes_per_band`：中间层节点数范围。
- `links_per_node`：每个节点连向下一层的边数。
- `skip_band_link_chance`：跨层连边概率。
- `extra_link_chance`：额外同层或近层连边概率。
- `elite_count` / `shop_count` / `rest_count` / `treasure_count`：各类节点数量。
- `event_ratio`：剩余节点中事件的比例，其余为战斗。

生成器保证全图从起点可达；如果随机结果出现不可达节点，会用 BFS 找最近节点补一条边。

## 后续接入点
