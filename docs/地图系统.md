# 地图系统

地图参考《杀戮尖塔》的节点推进方式，采用放射状分层结构：Boss 位于整张地图的正中心，其余节点按层环绕在它周围。每层节点数量不固定，同层相邻节点之间可能有一条环向捷径。

移动规则与《杀戮尖塔》不同：每一步可以选择**任意已探索节点的未探索邻居**，不必从当前所在节点出发；已经探索过的节点不能再次进入。因此玩家可以回到早先的分支点改走另一条路，但不会重复经过同一个节点。

## 节点类型

| 类型 | 说明 |
| --- | --- |
| 起点 | 每幕开始的位置，已自动访问，位于最外圈 |
| 战斗 | 普通战斗，胜利后获得金币 |
| 精英战斗 | 更难的战斗，金币更多 |
| 未知事件 | 随机触发一个事件，按选项结算 |
| 宝箱 | 获得金币 |
| 商店 | 购买卡牌或治疗，库存有限 |
| 休息点 | 恢复最大生命的一定比例 |
| 关底 Boss | 位于地图中心，进入后可以开启下一幕 |

## 崩解度

崩解度 = 本幕已访问节点数 / 本幕节点总数，每幕开始时重置。起点计入已访问，所以开局是 `1 / 节点总数`。已探索节点不能再次进入，因此每次移动都会提高崩解度。

目前只提供数值与信号（`MapRun.decay_changed`、`MapRun.act_completed`），尚未绑定任何减益效果，方便后续单独设计。

## 布局与连线

- Boss 固定在画布中心 `(0.5, 0.5)`，所在层为最内层。
- 起点在最外圈，只连一条边到第 1 层的节点。
- 第 1 层到倒数第 2 层，每个节点按角度等距分布；除 Boss 外，每个节点恰好连接一个更内层的「父节点」，取角度最近的那个。
- 同层节点数不少于 4 时，按角度排序后相邻节点之间按 `ring_link_chance` 概率生成环向捷径（首尾相连成环）；环向边绘制成沿该层椭圆的弧线。节点太少的层不加环向边，避免弧线横跨半张地图。
- 父边是径向直线，只跨越相邻两层；环向边只出现在同一层。因此边不会互相交叉，也不会穿过节点。

画布按 1.5:1 的椭圆铺开，节点半径根据层间距自适应，层数越多节点越小。

## 主要脚本

| 文件 | 职责 |
| --- | --- |
| `map/map_config.gd` | 地图生成参数（层数、每层节点数、环向边概率、各类节点数量） |
| `map/map_node.gd` | 单个节点：类型、层数、归一化坐标、相邻节点 |
| `map/map_graph.gd` | 节点集合与无向边，区分径向边和环向边，提供连通性检查 |
| `map/map_generator.gd` | 生成放射状分层地图、分配父节点与环向边、按配额分配节点类型 |
| `map/map_run.gd` | 一局游戏的地图进度：已探索节点、可前往节点、崩解度、切换幕 |
| `map/map_player_state.gd` | 生命、金币、卡组副本，供事件和商店结算 |
| `map/map_canvas.gd` | 绘制地图（径向边、环向弧线）并把点击换算成节点 |
| `map/map_view.gd` | 调试界面：顶栏、崩解度、节点面板 |

## 内容资源

- `map/data/map_config.tres`：默认地图参数。
- `map/data/map_content_pool.tres`：事件、商店库存、各类金币与治疗比例。
- `map/data/events/*.tres`：示例事件。
- `map/data/shop_stock.tres`：示例商店库存。

## 调整生成结果

在 `map/data/map_config.tres` 中修改：

- `band_count`：总层数，包含起点层、中间层和 Boss 层，Boss 在最内层。
- `min_nodes_per_band` / `max_nodes_per_band`：中间层节点数范围。
- `ring_link_chance`：同层相邻节点生成环向捷径的概率。
- `elite_count` / `shop_count` / `rest_count` / `treasure_count`：各类节点数量。
- `event_ratio`：剩余节点中事件的比例，其余为战斗。

生成器保证全图从起点可达；每个非 Boss 节点都有一个更内层的父节点，Boss 与最内层所有节点相连。

## 调试与测试

地图界面可以直接运行 `map/map_view.tscn`。战斗系统尚未接入，战斗与精英节点暂时用「视为胜利」按钮跳过并发放金币。

```bash
godot --headless --path . -s res://map/tests/map_smoke_test.gd
godot --headless --path . -s res://map/tests/map_view_smoke_test.gd
```

`map/tests/map_capture.gd` 会在无头模式下渲染一张地图到 `map/tests/layout_preview.png`，用于目检布局。
