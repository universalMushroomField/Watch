## 当前阻塞项

按"没有它就没法继续做"排序：

1. **W-01 符号定名** —— 所有卡牌文案、序列 UI、教程都依赖它。
2. **W-02 + N-01 卡表** —— 战斗能做，但没法测平衡、没法做卡池。
3. **A-01 序列条 UI** —— 现在的序列是文字按钮，新玩家无法理解机制。
4. **金币产出** —— 战斗不结算奖励，商店与事件的经济全部空转（见 `docs/商店系统.md`）。
