# 敌人与 Boss

> 状态：机制已实现，内容（血量、行为、数值）全部未设计。
> 代码：`character/scripts/enemy.gd`、`character/scripts/enemy_action_state.gd`
> 相关：`docs/战斗系统.md`、`docs/主题与叙事.md`、`docs/资源需求.md`

## 设计目标

敌人不出牌、不抽牌，按预设状态机行动，玩家在已知本回合意图的前提下出牌（参考杀戮尖塔）。敌人的难度来自行为组合，而不是资源管理。

## 当前实现

- `Enemy extends Character`，持有 `action_states: Array[EnemyActionState]` 与 `initial_state`。
- 每个 `EnemyActionState`：`intent_text`（意图文案）、`effects`（效果列表）、`next_state`（后继状态）。
- 敌方回合按 `BaseFight.enemies` 数组顺序行动，每个敌人每回合行动一次。
- 行动结算后 `current_state = next_state`，`reset_action_state()` 可在战斗开始时复位。
- 意图文案显示在精灵上方，死亡后隐藏。
- 状态机是线性的：没有随机分支，也没有条件分支。

## 设计缺口

| 缺口 | 说明 |
| --- | --- |
| 数值 | 血量、护甲、伤害、行动频率全部空白 |
| 行为选择 | 状态机只有线性后继，没有随机权重或条件分支 |
| 塞牌 / 塞块 | 需要新效果：往抽牌堆或手牌插入牌、往序列插入符号 |
| 召唤衍生物 | 需要在战斗内动态添加 `Enemy` |
| 状态系统 | "疯狂 / 增伤 / 混乱 / 误导 / 疾病"没有 buff/debuff 容器，目前只有护甲和一次性伤害抵消 |
| 多段与阶段 | 没有多段行动、阶段转换、抗性 |
