## 收集品

局内获得，带正面、负面或二者兼有的效果，一般只在局内留存，局外只解锁图鉴。

需要的数据：

| 数据 | 内容 |
| --- | --- |
| `RelicData` | id、名称、描述、图标、触发时机、效果列表 |
| 持有列表 | 玩家当前携带的收集品 |
| 触发点 | 战斗开始、回合开始、出牌、受伤、进入节点、结算 |

触发点可以和现有的 `Effect` 体系对齐：收集品 = 一组 `Effect` + 一个触发阶段（`BattlePhase.Stage`）。这样不需要新写一套效果类型。

待定：

- 槽位上限，是否可丢弃。
- 正负效果是否同源（一个收集品同时有增益和代价）。
- 图鉴解锁条件：获得过即解锁，还是需要达成某条件。
- 是否影响地图层（例如改变崩解度增速）。

## 局外养成

每局结束按评价获得资源，进行主动或被动养成，主要用于解锁卡牌与收集品。

需要的数据：

| 数据 | 内容 |
| --- | --- |
| 评价维度 | 回合数、崩解度、剩余生命、击败数，权重待定 |
| 局外货币 | 由评价换算 |
| 解锁表 | 卡牌、收集品、角色 |
| 存档 | 局外进度持久化 |

依赖：存档。`run/scripts/run_state.gd` 的 `load_run()` 目前是空实现并返回 `false`，局外进度还没有落盘位置。
