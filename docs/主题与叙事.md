# 主题与叙事

> 本文照录提案中的世界设定与文案，不改写措辞。崩解度的数值定义见 `docs/地图系统.md`，敌人行为见 `docs/敌人与Boss.md`。

## 世界设定

有一类危险的生物种类，只有少数有智慧，他们的危险程度取决于其中有智慧的个体的极端程度，这些个体越极端，生物整体越危险，然后崩解度 == 极端度，我们扮演清理这些生物侵犯到人类生活空间的人（之类的），我们清理的深入过程被智慧个体观察，然后在清理过程这些智慧个体越来越极端。

## 崩解度 = 极端度

极端度：智慧个体在"被观察、被清剿"的过程中不断接收刺激，把整个族群推向更狂热、更疯狂的形态；同时，由于极端度，高极端度不仅意味着敌人更凶残，还意味着地图环境与战斗规则正在发生剧烈崩解。

崩解度在代码中由"已访问节点占非起点节点的比例"计算，每幕重置，见 `docs/地图系统.md`。

## 叙事与机制的关系

- 一幕 = 一次清理的推进。崩解度随探索上升，进入下一幕重置（当前实现）。
- 阶段推进的触发条件待定：按崩解度阈值，还是按幕数，还是两者组合。
- 人类方文案的载体待定：图鉴、幕间旁白、还是结算界面。
- 阶段效果（崩解度带来的规则变化）与"更凶残的敌人 + 更剧烈的环境崩解"要落到具体数值，见 `docs/资源需求.md` N-05。
